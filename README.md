# NextVacation — החופשה הבאה

גרסת MVP מלאה של מנוע חיפוש והשוואת תיירות בעברית (RTL), ללא Checkout וללא סליקה באתר.

## מה כולל הפרויקט
- עמוד בית מלא במיתוג NextVacation
- חיפוש טיסות עם autocomplete לשדות תעופה, הלוך ושוב / כיוון אחד, מחלקה ונוסעים
- תוצאות טיסות עם מיון וסינון פעילים (מחיר, ישירות, חברות תעופה)
- חיפוש מלונות עם אורחים וחדרים
- תוצאות מלונות עם מיון וסינון פעילים
- עמוד טיסה + מלון עם שילובי Demo
- מודל הפניה לספק במקום תשלום באתר
- עמודי איך זה עובד, אודות, צור קשר, פרטיות, תנאים וגילוי נאות
- מובייל מלא + תפריט RTL כשההמבורגר בצד ימין
- נתוני Demo ברורים לצורך הצגת MVP לספקי API/Affiliate

## הפעלה מקומית
```bash
npm install
npm run dev
```
ואז לפתוח `http://localhost:3000`.

## בדיקת Production
```bash
npm run build
npm start
```

## חיבור ספק אמיתי בהמשך
1. ליצור Route פנימי כגון `/api/flights/search` ו־`/api/hotels/search`.
2. לשמור מפתחות API ב־Environment Variables בלבד.
3. להחליף את המערכים ב־`lib/data.ts` בתוצאות מה־API.
4. בכפתורי `ProviderButton` להחליף את מודל ההדגמה ב־Deep Link / Affiliate URL שמוחזר מהספק.
5. להסיר `robots: { index:false }` ב־`app/layout.tsx` רק כאשר התוכן, המדיניות והנתונים חיים ומוכנים לאינדוקס.

## הערות משפטיות
עמודי פרטיות/תנאים הם טיוטות MVP בלבד ויש לבצע התאמה משפטית לפני השקה מסחרית.
