# NextVacation V6

עדכון עיצובי לפי קו ההשראה האחרון:

- היררכיית כותרות מאוזנת: כותרות המשנה הקטנות גדולות וברורות יותר, והכותרות הראשיות רגועות ואחידות.
- 8 אייקוני קטגוריה חדשים שנוצרו אחד-אחד בסגנון coastal / boho רך. אין חיתוכים מתוך קולאז׳.
- עמוד ברצלונה נבנה מחדש בסגנון travel journal / editorial collage: טקסט + קולאז׳ תמונות, כרטיסי מידע, אזורים, נקודות עניין וגלריה.
- Footer: הוסר הטקסט שמתחת ללוגו; החלק התחתון הוגדל, בעוד תפריטי הקישורים נשארו בגודל מאופק.
- שפה חזותית חמימה יותר לכל האתר: נייר, ורוד מעושן, ירוק מרווה, חול וצללים רכים.
