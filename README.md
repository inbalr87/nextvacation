# NextVacation V5

גרסת תיקונים מלאה לפי ההערות האחרונות.

## מה השתנה
- בדף הבית: הטאבים טיסות / מלונות / טיסה + מלון / דילים מחליפים מצב בתוך אותה חלונית, בלי לעבור עמוד.
- דילים נוסף לחיפוש הראשי.
- טיפוגרפיה הוגדלה ואוחדה בכל האתר, כולל פוטר ותוצאות טיסות.
- עמוד הטיסות כולל כרטיסי יעד עם תמונות.
- דפי הקטגוריות כוללים תמונה לכל יעד.
- אייקוני הקטגוריות נבנו מחדש כקבצי SVG נפרדים ונקיים.
- אזור ההשראה בדף הבית משתמש בתמונות יעד מקצועיות.
- האזור "מה תרצו להשוות?" הוסר מהדף הראשי.
- עמוד דילים ללא כותרות אנגליות, עם חיפוש מוכן לחיבור ספק חי.
- נבנה דף יעד לדוגמה לברצלונה: `/destinations/barcelona`.
- `lib/destinations.ts` כולל את רשימת היעדים הפופולריים שסוכמה, כהכנה לבניית שאר דפי היעד.

## העלאה
החליפו את תוכן תיקיית הפרויקט המקומית בתוכן הקובץ, השאירו את `.git` המקומי, ואז:
1. GitHub Desktop → Commit to main
2. Push origin
3. Vercel יפרוס אוטומטית.
