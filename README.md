# NextVacation – refreshed MVP

גרסת MVP מעודכנת של "החופשה הבאה".

## מה השתנה בגרסה הזו
- Hero בדף הבית: תמונה משמאל וטקסט מימין בדסקטופ.
- שלוש החלוניות שמתחת לתמונת ה-Hero לחיצות ובכתב גדול יותר.
- חיפוש טיסות כולל: הלוך ושוב, כיוון אחד, מספר יעדים ומחלקת טיסה.
- מחלקת טיסה מוצגת כשדה מלא גם בטיסה + מלון.
- עמודי טיסות / מלונות / טיסה + מלון קיבלו Hero מאויר רחב עם Search Box חופף.
- עמודי קטגוריה חדשים: חופשה אורבנית, שופינג, דקה 90, צפון אמריקה, חופים, אוכל, משפחות וחיי לילה.
- עמוד דילים חדש שלא ממציא מחירים: דילים חיים יוצגו רק לאחר חיבור ספק נתונים.
- עמוד מלונות כולל יעדים פופולריים לחיפוש.
- עמוד טיסה + מלון כולל רעיונות לשילוב באותו יעד, בלי מחיר מומצא ועם כפתור פעולה אחד.
- ניווט כולל דף דילים.

## העלאה
העתיקו את כל תוכן התיקייה לתיקיית הפרויקט המקומית שמחוברת ל-GitHub Desktop, אשרו Replace, ואז:
1. Commit to main
2. Push origin
3. Vercel יבצע Deploy אוטומטי

הערה: תוצאות הטיסות והמלונות הקיימות הן נתוני MVP להדגמת הממשק עד לחיבור API / Affiliate חי.
